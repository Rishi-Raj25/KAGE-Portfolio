# KAGE Portfolio

A full-page KAGE landing experience built with Next.js and the official `@designcodeio/threeui` React component.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## KAGE configuration

The homepage renders the official `KageLandingPage` component with Onest typography and the red accent color `#e0231c`.
